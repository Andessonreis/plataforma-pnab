# Screenshots dos bugs

Cada bolsista tem sua subpasta aqui. Suba os screenshots dos bugs que você encontrar.

## Convenção de nome

```
T###-descricao-curta.png
```

Exemplos:
- `T025-erro-ao-habilitar-inscricao.png`
- `T040-xss-nao-escapado.png`
- `EXPLIVRE-01-botao-duplica-ao-clicar-2x.png`

## Como tirar screenshot

- **Windows:** `Win+Shift+S` (Snipping Tool) → seleciona área → Ctrl+V num arquivo, ou clica em "Salvar"
- **Mac:** `Cmd+Shift+4` → seleciona área → salva no Desktop
- **Celular (T060):** Print da tela do celular mesmo (Power+Volume- ou Power+Home)

## Como subir aqui

1. Abra sua subpasta (com seu nome)
2. Arrastar o arquivo do desktop pra dentro da pasta do Drive
3. Clique direito no arquivo → "Obter link" → "Qualquer pessoa com link pode ver"
4. Cole o link na coluna `Screenshot_ou_link` da planilha

## Se o bug tem várias telas

Tire UM print por tela e numere: `T025-erro-habilitar-01.png`, `T025-erro-habilitar-02.png`, etc.

## Se é uma GIF (mais útil que print)

Use https://www.screentogif.com/ (Windows) ou Kap (Mac) e salve como `.gif`.
