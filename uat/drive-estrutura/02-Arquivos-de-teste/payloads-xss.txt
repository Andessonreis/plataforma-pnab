PAYLOADS DE TESTE XSS — para a tarefa T019 (Cauã Gomes)

Cole um dos payloads abaixo no campo "Descrição do projeto" ou qualquer
campo de texto livre. Submeta. Depois peça pra um admin (Caio) abrir a
inscrição. Se o alert aparecer na tela, é bug GRAVE — reporte
imediatamente com severidade BLOQUEADOR.

RESULTADO ESPERADO: texto aparece LITERAL (escapado), sem executar o JS.

-----------------------------------------------------------
PAYLOAD 1 — Clássico
-----------------------------------------------------------
<script>alert('xss')</script>

-----------------------------------------------------------
PAYLOAD 2 — Via atributo de imagem
-----------------------------------------------------------
<img src=x onerror="alert('xss via img')">

-----------------------------------------------------------
PAYLOAD 3 — Via atributo SVG
-----------------------------------------------------------
<svg onload="alert('xss via svg')">

-----------------------------------------------------------
PAYLOAD 4 — javascript: em href
-----------------------------------------------------------
<a href="javascript:alert('xss em link')">clique aqui</a>

-----------------------------------------------------------
PAYLOAD 5 — Escape de atributo
-----------------------------------------------------------
" onmouseover="alert('xss escape')" x="

-----------------------------------------------------------
PAYLOAD 6 — Unicode encoding
-----------------------------------------------------------
<script>alert('xss unicode')</script>

-----------------------------------------------------------
PAYLOAD 7 — Nested tags
-----------------------------------------------------------
<scr<script>ipt>alert('xss nested')</scr</script>ipt>

-----------------------------------------------------------
PAYLOAD 8 — Markdown link (se o campo aceita markdown)
-----------------------------------------------------------
[texto](javascript:alert('xss markdown'))

-----------------------------------------------------------
PAYLOAD 9 — Tag iframe
-----------------------------------------------------------
<iframe src="javascript:alert('xss iframe')"></iframe>

-----------------------------------------------------------
PAYLOAD 10 — Event handler em div
-----------------------------------------------------------
<div onclick="alert('xss onclick')">clique</div>

-----------------------------------------------------------
COMO TESTAR CADA UM
-----------------------------------------------------------
1. Cole o payload no campo de texto
2. Clique Salvar / Submeter
3. Abra a inscrição (a mesma ou pede pra admin ver)
4. Se aparecer uma popup de alert = BUG BLOQUEADOR
5. Se texto aparecer escapado (com &lt; &gt;) ou literal como texto = OK

Marque na planilha qual payload você usou em cada tentativa.
