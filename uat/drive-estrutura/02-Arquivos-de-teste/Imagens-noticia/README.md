# Imagens para notícias (T003)

Gabriel Barauna usa aqui quando for criar uma notícia com imagem.

## Precisa ter

- `noticia-destaque-1.jpg` — 1200×630 (proporção de cover/Open Graph)
- `noticia-destaque-2.jpg` — 1200×630
- `imagem-grande.png` — >5MB pra testar compressão/limite (se houver)

## Sugestão de origem

- **Fotos livres de direito:**
  - https://www.pexels.com/pt-br/procurar/cultura/
  - https://unsplash.com/s/photos/culture-brazil
  - https://pixabay.com/pt/images/search/cultura/
- **Evitar:** fotos com rostos identificáveis (privacidade), imagens com marca d'água

## Temas que funcionam bem

Pontos de cultura, oficinas, apresentações musicais, teatro, dança, artesanato. Priorize cenas brasileiras/nordestinas se possível.
