# PDFs válidos para upload

Nesta pasta ficam PDFs de teste aceitos pelo sistema (< 10 MB, formato PDF real).

Os bolsistas que vão se inscrever (T014, T015, T016, T017, T020, T022) baixam daqui e sobem no wizard de inscrição.

## Precisa ter

- `projeto-exemplo.pdf` — simulando um documento de projeto (1–3 páginas, ~500KB)
- `portfolio-exemplo.pdf` — simulando portfólio (5–10 páginas, ~2MB)
- `orcamento-exemplo.pdf` — simulando orçamento
- `documento-identidade-exemplo.pdf` — simulando RG/CPF

## Como gerar rapidamente

Se não tiver à mão:
- https://www.ilovepdf.com/pt/pdf_para_jpg (converter imagem → PDF)
- https://smallpdf.com/pt/jpg-para-pdf
- Ou no Word/Google Docs: "Salvar como PDF"

**Importante:** sem dados pessoais reais nos arquivos de teste.
